aSAH Nursing Transfer & Neurological Monitoring

แนวปฏิบัติการพยาบาลเพื่อเฝ้าระวังการทรุดลงทางระบบประสาท ในผู้ป่วย Aneurysmal Subarachnoid Hemorrhage ที่ได้รับการส่งต่อระหว่างโรงพยาบาลก่อน definitive aneurysm treatment

🚨 RED FLAGS

GCS ลดลงจาก baseline
Pupil เปลี่ยนแปลง / ไม่เท่ากัน
Motor deficit ใหม่หรือแย่ลง
Seizure
SpO₂ ลดลง / Airway problem
BP / Circulation unstable
สงสัย Rebleeding
สงสัย Acute hydrocephalus
ยังไม่พบข้อมูล Red Flag

เมื่อพบ Red Flag

ABC + Neuro ซ้ำทันที → ให้การช่วยเหลือตามแผนการรักษา → แจ้งศูนย์รับ–ส่งต่อ/แพทย์ทันที → บันทึกเวลา อาการ การช่วยเหลือ และ Response

หากเดิมอยู่ WFNS I–III แล้วเกิด Red Flag ให้เพิ่มความเข้มข้นการดูแลเทียบเท่า WFNS IV–V โดยไม่เปลี่ยน WFNS Grade จนกว่าจะประเมิน GCS/Motor ใหม่
